# 🍽️ منصة B2B لطلبات المقاهي والمطاعم (B2B Food & Cafe Ordering Network)

نظام ويب متكامل واحترافي مبني باستخدام **Django** ومرتبط مباشرة بقاعدة بيانات **Supabase (PostgreSQL)**، مخصص لإدارة وتمرير طلبات الوجبات والمشروبات داخلياً بين المقاهي (Cafes) والمطاعم (Restaurants).

---

## 🌟 مميزات النظام الأساسية

### 1. إدارة المستخدمين والصلاحيات (Authentication & Roles)
- **إنشاء الحسابات:** محصور حصراً بالإدارة الرئيسية (**Superuser**) عبر لوحة الإدارة (`/admin/`). لا يوجد تسجيل ذاتي مفتوح لحماية بيئة العمل B2B.
- **تحديد الأدوار:** المشرف يحدد نوع الحساب: `مطعم (RESTAURANT)` أو `كافيه (CAFE)`.
- **التوجيه التلقائي:** عند تسجيل الدخول، يتم توجيه كل مستخدم تلقائياً إلى لوحة التحكم الخاصة به وفقاً لصلاحياته.
- **حماية المسارات:** مزخرفات مخصصة (`@restaurant_required` و `@cafe_required`) تمنع دخول أي طرف لصفحات الطرف الآخر.

---

### 2. صلاحيات وواجهة المطعم (Restaurant Portal)
- **لوحة معلومات ذكية (Dashboard):** مؤشرات حية لطلبات اليوم، الطلبات المعلقة، الإيرادات التقديرية، وعدد الأصناف.
- **إعداد الملف الشخصي والشعار (Logo & Profile):** إمكانية رفع شعار المطعم، صورة الغلاف، أرقام التواصل، والعنوان، مع خيار تشغيل/إيقاف استقبال الطلبات.
- **إدارة الفئات (Categories):** تنظيم القائمة في أقسام مثل (مشويات على الفحم، مقبلات، عصائر، برجر...) مع أيقونات وترتيب مخصص.
- **إدارة قائمة الطعام (Menu Items):** إضافة الأصناف بالأسعار، الصور، أوقات التحضير، ووصف المكونات، مع مفتاح تبديل فوري (AJAX) لتوفر الصنف (متوفر / غير متوفر).
- **شاشة استقبال الطلبات الحية (Live KDS Screen):**
  - عرض حي للطلبات الواردة من الكافيهات مع تحديث تلقائي (Polling كل 8 ثوانٍ).
  - تنبيه صوتي وتنبيه بصري فوري عند ورود طلب جديد من أي كافيه.
  - فرز الطلبات حسب الحالة: (قيد الانتظار، قيد التحضير، جاهز للتسليم، مكتمل، ملغي).
  - أزرار سريعة بضغطة واحدة لنقل حالة الطلب: **[قبول والبدء بالتحضير]** -> **[جاهز للتسليم]** -> **[تم التسليم بنجاح]**.

---

### 3. صلاحيات وواجهة الكافيه (Cafe Portal)
- **شبكة المطاعم الشريكة (Directory Grid):** استعراض جميع المطاعم المسجلة بشعاراتها، صور أغلفة، عدد الأصناف المتاحة، العناوين، وشريط بحث سريع.
- **تصفح المنيو بتصميم جذاب (Card-based UI):**
  - ترويسة أنيقة بمعلومات المطعم وتفاصيل التواصل.
  - تصفية سريعة للأصناف عبر أزرار التصنيفات (Pills) بدون إعادة تحميل الصفحة.
  - بطاقات عصرية للأصناف تحتوي على الصورة، السعر، وقت التحضير، والوصف.
- **سلة تفاعلية فورية (Interactive Cart):**
  - اختيار الأصناف وتحديد الكميات بدقة (+ / -).
  - إمكانية إضافة ملاحظات خاصة لكل صنف (مثل: "بدون مخلل").
  - حقل إلزامي لتحديد رقم الطاولة أو مرجع الزبون (مثال: "طاولة رقم 5").
  - حقل للملاحظات العامة على الطلب.
  - حساب المجموع الفرعي والإجمالي تلقائياً.
  - زر إرسال الطلب (Place Order) الذي يسجل الطلب فوري في لوحة المطعم عبر معالجة ذرية (Atomic Transaction).
- **سجل الطلبات والتتبع الحي (Order Tracking & History):**
  - شريط تقدم مرئي يوضح مسار الطلب لحظة بلحظة: (تم الإرسال ⬅️ قيد التحضير ⬅️ جاهز للاستلام ⬅️ تم التسليم).
  - عرض الفاتورة التفصيلية مع إمكانية طباعة الإيصال بضغطة زر.

## 🚀 خطوات التشغيل السريعة (Step-by-Step)

### 1. تثبيت الحزم المطلوبة (Dependencies):
```bash
pip install -r requirements.txt
```

### 2. عمل الـ Migrations (تم تطبيقها مسبقاً على Supabase):
```bash
python manage.py makemigrations
python manage.py migrate
```

### 3. إدخال البيانات التجريبية الجاهزة (Seed Data):
تم توفير أمر مخصص لبذر بيانات حقيقية تشمل المشرف العام، مطعمين بقوائم طعام كاملة، وكافيهين، وطلب تجريبي:
```bash
python manage.py seed_data
```

### 4. تشغيل السيرفر المحلي:
```bash
python manage.py runserver
```
ثم افتح المتصفح على: `http://127.0.0.1:8000/`

## 📁 هيكلية ملفات المشروع (Project Structure)

```text

├── b2b_orders/              # تطبيق إدارة الطلبات B2B

├── templates/               # قوالب HTML الحديثة (Bootstrap 5 RTL + Cairo Font)
```
